# Harsh Pratap Portfolio 🚀

A modern and responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my skills, projects, experience, and achievements.

---

## 🌐 Live Demo

harsh-portfolio-sable.vercel.app

---

## 📌 Features

- Responsive Modern UI
- Smooth Scrolling Navigation
- Animated Hover Effects
- Projects Showcase Section
- Skills Section
- Work Experience Timeline
- Contact Form Integration
- Download Resume Button
- Social Media Links
- Fully Mobile Responsive

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Vercel Deployment
